# ujaan.me

My personal corner of the web - a portfolio, blog, and digital playground for random experimentations. I like discussing new ideas, sharing work, and documenting what I'm learning and reading.

## Built with:

- Framework: [Astro](https://astro.build/)
- UI & Styling: [React](https://react.dev/), [Tailwind CSS](https://tailwindcss.com/)
- Content Management: [Keystatic](https://keystatic.com/)
- Deployment & Hosting: [Cloudflare Pages](https://pages.cloudflare.com/) (but will self-host when I can get my homelab up and running again!)
